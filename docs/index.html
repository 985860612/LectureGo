使用教程

五步完成多源分轨录制

从接入画面到进入 DaVinci Resolve 后期，第一次使用也能按顺序完成。

  1. 01

    添加录制来源

    点击来源栏右侧“添加”，选择屏幕、窗口、摄像头、移动端、外部 RTMP 或麦克风。移动端与 Mac 保持在同一局域网即可发现。

  2. 02

    加入输出并编排场景

    把需要出现在成片中的视频加入输出图层，拖动调整位置和大小，或直接套用全屏、画中画、分栏布局。

  3. 03

    开启独立轨道

    在每个视频或音频来源卡片上启用“录制独立文件”。成片布局只影响合成画面，不会破坏各来源的完整素材。

  4. 04

    设置输出并开始录制

    在底栏打开输出设置，选择横屏或竖屏、分辨率、帧率、编码和码率。确认磁盘空间后点击“开始录制”。

  5. 05

    导入 DaVinci Resolve

    录制结束后，在 Resolve 选择“文件 → 导入 → 时间线”。18.1–18.4 使用 课录.xml，18.5 及以上优先使用 课录.otio。

录制结果 成片 + 视频 ISO + 独立音轨 + Resolve 多轨时间线 + 录制报告
