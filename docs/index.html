开始使用

在 macOS 上构建开讲

需要 macOS 14+ 与 Swift 5.9+。首次运行请授权屏幕录制、摄像头、麦克风和局域网访问。

git clone https://github.com/985860612/LectureGo.git
cd LectureGo
./scripts/build-app.sh
open CourseRec.app
