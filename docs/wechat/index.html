一边留下完整后期空间

一个为课程创作者准备的多源录制工作台：屏幕、摄像头、手机、RTMP 和麦克风同时接入，每一路都能独立成轨。

开讲 LectureGo · 多源课程录制工作台

做课程视频时，我们经常遇到一个两难：

直接录成片，效率很高，但镜头位置、画面裁切和声音比例一旦录死，后期就很难再改。

分别录屏幕、摄像头和声音，后期空间有了，却要面对多个工具、多份素材和难以对齐的时间线。

开讲想解决的，就是“快速得到成片”和“完整保留后期”之间的矛盾。

01 · 多源统一接入

不是简单录屏，而是课程录制工作台

在同一个窗口里，你可以按需要组合多种输入来源：

屏幕与窗口 摄像头
Android 移动端 外部 RTMP
系统声音 多个麦克风

讲师画面、课件、演示设备和声音不再散落在不同软件里，接入后即可统一监看和控制。

02 · 成片与独立轨道同录

录制结束，不只有一个视频文件

开讲会实时生成当前布局的成片，同时把每一路原始素材独立保存。场景里的裁切和画中画，不会破坏原始画面。

一次录制得到的内容
成片 当前场景的合成视频
视频 ISO 每路画面独立文件
独立音轨 系统声与麦克风分开保存
后期时间线 Resolve XML / OTIO

成片可以马上交付，独立轨道可以继续精修。

03 · 场景实时编排

横屏、竖屏、画中画，录制中也能调整

把需要出现在成片里的来源加入输出，拖动改变位置和大小，或者直接套用全屏、画中画、讲解分栏和均分对照布局。

添加来源：屏幕、窗口、摄像头、移动端、RTMP 和麦克风

04 · 完整进入后期

打开 DaVinci Resolve，素材已经对齐

开讲可以导出 DaVinci Resolve XML 与 OTIO 多轨时间线。视频 ISO、独立音轨和录制标记自动放到对应轨道，减少手工导入和对齐素材的重复工作。

Resolve 18.1–18.4 使用 XML；18.5 及以上优先使用 OTIO。

05 · 输出参数

针对不同课程，统一维护输出质量

横屏或竖屏、分辨率、帧率、H.264 / HEVC 编码和码率集中设置。开始录制前，工作台还会提示来源实际帧率和预计磁盘占用。

输出设置：方向、分辨率、帧率、编码和码率

五步开始录制

第一次使用，也能顺着完成

01 添加录制来源

选择屏幕、窗口、摄像头、移动端、RTMP 或麦克风。

02 编排输出场景

加入输出图层，调整位置和大小，或者套用布局。

03 启用独立录制

需要进入后期的画面和声音，分别开启“录制独立文件”。

04 设置输出并录制

确认方向、分辨率、帧率、编码、码率和磁盘空间。

05 交付成片或继续后期

直接使用成片，或把 XML / OTIO 时间线导入 DaVinci Resolve。
